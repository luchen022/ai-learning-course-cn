# 注意力与 Transformer

## Q、K、V

自注意力中，每个位置通过 Query 与其他位置的 Key 计算匹配分数，归一化后对 Value 做加权平均。多头注意力在不同的表示子空间并行计算，再合并结果。

## 因果掩码

自回归语言模型预测下一个 Token 时，当前 Token 不能读取未来位置。因果掩码把未来位置的注意力分数设为负无穷，softmax 后这些位置权重为零，因此过去位置的输出不依赖未来输入。

## Transformer 块

常见 Transformer 块含注意力、前馈网络、残差连接与 LayerNorm。残差为信息与梯度提供直接路径；位置编码或位置信息让模型区分 Token 顺序。
