向量与矩阵求导

一个函数的自变量是向量或矩阵时，怎样求导？导数又表示什么？从你会的一元求导出发，先逐个元素计算，再把结果组织起来。

偏导的定义向量梯度雅可比矩阵矩阵梯度变化量的意义

学习路径

01 先看函数与自变量02 标量函数对向量求导03 向量函数对向量求导04 例子：元素平方后求和05 矩阵输出怎样求导06 复合函数的求导07 数值验证与练习08 自测
学习方法：每遇到一个函数，先展开它，辨认独立的自变量。每次只改变其中一个，固定其他自变量，用你会的标量规则求导；最后再看这些偏导应该排成什么形状。

01 / 从一元导数到偏导

向量和矩阵里，每个元素都可以是一个自变量

你熟悉 f(t)=t² 的导数 f′(t)=2t。它表示：在当前位置，让 t 增加一个很小的 ε，函数值大约增加 2t×ε。

现在把两个数组织成向量 x=[x₁,x₂]，定义 f(x)=x₁²+2x₂²。这个写法只是 f(x₁,x₂) 的简写。函数依赖两个独立变量，可以分别问“只改变 x₁ 会怎样”和“只改变 x₂ 会怎样”。

偏导怎么求？固定其他变量

只让 x₁ 变化：把 x₂ 当成常数，∂f/∂x₁ = 2x₁
只让 x₂ 变化：把 x₁ 当成常数，∂f/∂x₂ = 4x₂

∂ 读作“偏导”的符号。定义和一元导数一样，只是这里明确规定其他自变量不动：

∂f/∂x₁ = limε→0 [f(x₁+ε,x₂)−f(x₁,x₂)] / ε

这个定义说的是：只移动一个输入坐标，观察函数值的变化率。向量和矩阵只是组织这些坐标的方式；求导时仍然可以把每个元素当作一个标量变量。

三个常见问题，对应三种结果

标量函数，向量自变量

一个函数值，两个独立输入。

x=[x₁,x₂]
f(x)=x₁²+2x₂²
∇f=[2x₁,4x₂]

整体运算：把 x 的每个元素平方，第二个乘 2，再把两个数相加。

每个输入对应一个偏导；排成向量，叫梯度。

意义：输入的各个分量怎样影响同一个函数值。

向量函数，向量自变量

两个函数值，两个独立输入。

F(x)=[x₁²+x₂, x₁x₂]
J = [[2x₁,1],
　　 [x₂,x₁]]

每个输出对每个输入都有偏导；排成一张表，叫雅可比矩阵。

意义：每个输入分别怎样影响每个输出。

标量函数，矩阵自变量

一个函数值，四个独立输入。

A=[[a,b],[c,d]]
f(A)=sum(A ⊙ A)
　=a²+b²+c²+d²
∂f/∂A=2A

整体运算：⊙ 表示对应位置相乘，sum 表示把所有元素相加，所以这个函数把一张矩阵变成一个数。

对每个格子分别求偏导，放回原位置，得到矩阵梯度。

意义：每个矩阵元素怎样影响同一个函数值。

先不要背结果。下面会把这三个例子的每一步展开。这里小写 f 表示标量输出，大写 F 表示多个输出，都是普通数学函数。

本课约定：标量函数的梯度按自变量原来的形状排列；雅可比的行对应输出，列对应输入。默认各个输入元素独立，不附加对称矩阵等约束。其他教材可能采用转置约定，读公式时要先看它的排列方式。

02 / 标量函数对向量求导

分别求偏导，再按输入顺序排成梯度

先看整体运算，再展开成标量

最简单的例子是“向量和自己做点积”。点积就是两个向量对应位置相乘，再把结果相加；符号是中间的点 ·。

x=[x₁,x₂]
x · x = x₁×x₁ + x₂×x₂ = x₁²+x₂²
例如 x=[2,1]：x · x = 2×2+1×1=5

所以 h(x)=x·x 是一个输入整个向量、输出一个数的函数。展开后看见标量运算，是因为点积本来就是这样计算的，不代表输入变成了标量。分别求偏导，就得到 ∇h=[2x₁,2x₂]=2x。

本页的 f 多了一步：第二个位置的平方乘 2。把“对应位置相乘”记作 ⊙，把“所有元素相加”记作 sum，则同一个函数可以写成：

f(x)=sum([1,2] ⊙ (x ⊙ x))
也可以写成点积：f(x)=x · [x₁,2x₂]
展开后：f(x)=x₁²+2x₂²
x=[2,1]
① x ⊙ x = [4,1]
② [1,2] ⊙ [4,1] = [4,2]
③ sum([4,2]) = 6

整体运算和逐元素展开是同一个函数的两种写法。向量形式方便看整体；展开形式方便用你已学的标量规则求偏导。这里 [x₁,2x₂] 也随 x 变化，不是一个固定的常量向量，求导时仍需展开计算。

现在逐个求导

x=[x₁,x₂]，f(x)=x₁²+2x₂²
  1. 对 x₁ 求导时，2x₂² 是常数，所以 ∂f/∂x₁=2x₁。
  2. 对 x₂ 求导时，x₁² 是常数，所以 ∂f/∂x₂=4x₂。
  3. 按 x₁、x₂ 的次序，把两个结果排好：∇f=[2x₁,4x₂]。
一般地，x=[x₁,…,xₙ]：
∇f(x) = [∂f/∂x₁,…,∂f/∂xₙ]

梯度的意义：预测这个函数值怎样变化

在 x=[2,1] 时，f=6，梯度为 [4,4]。这表示：只让 x₁ 增加很小的 ε，f 大约增加 4ε；只让 x₂ 增加很小的 ε，f 也大约增加 4ε。

两个分量一起变化时，把各自的贡献相加。设 Δx=[Δx₁,Δx₂]：

Δf ≈ (∂f/∂x₁)Δx₁ + (∂f/∂x₂)Δx₂
　 = ∇f · Δx
f(x+Δx) ≈ f(x) + ∇f · Δx

例如 Δx=[0.1,0]，梯度预测 Δf≈4×0.1=0.4；实际 f(2.1,1)−f(2,1)=0.41。导数描述局部的一阶变化，所以对于一般非线性函数，有限改动下通常是近似。

动手：分别改变两个分量

分量之间有乘积，也照样逐个求导

g(x)=x₁²+x₁x₂+2x₂²
∂g/∂x₁=2x₁+x₂　（对 x₁ 求导，x₂ 是常数）
∂g/∂x₂=x₁+4x₂　（对 x₂ 求导，x₁ 是常数）
∇g=[2x₁+x₂, x₁+4x₂]

在 x=[2,1] 时，g=8、∇g=[5,6]。向量函数的表达式不需要每个分量各算各的；关键仍然是每次只对一个自变量求偏导。

03 / 向量函数对向量求导

每个输出都求一遍，得到雅可比矩阵

这次输出不再是一个数，而是两个数：

F(x)=[f₁(x),f₂(x)]
f₁=x₁²+x₂
f₂=x₁x₂

不要直接猜“向量的导数”。先对 f₁ 求两个偏导，再对 f₂ 求两个偏导：

输出函数对 x₁ 求导（固定 x₂）对 x₂ 求导（固定 x₁）
f₁=x₁²+x₂2x₁1
f₂=x₁x₂x₂x₁
Jᵢⱼ = ∂fᵢ/∂xⱼ
J = [[∂f₁/∂x₁, ∂f₁/∂x₂],
　　 [∂f₂/∂x₁, ∂f₂/∂x₂]]
　= [[2x₁,1],
　　 [x₂,x₁]]

n 个输入、m 个输出时，一共有 m×n 个偏导，雅可比是 m 行 n 列。某个输出不依赖某个输入，对应的格子就是 0。

雅可比的意义：把输入变化换算成各个输出的变化

在 x=[2,3] 时，F(x)=[7,6]、J=[[4,1],[3,2]]。只让 x₁ 增加 ε，两个输出分别大约增加 4ε、3ε；这就是雅可比第一列的含义。只让 x₂ 增加 ε，则分别增加 ε、2ε，对应第二列。

Δf₁ ≈ 2x₁Δx₁ + Δx₂
Δf₂ ≈ x₂Δx₁ + x₁Δx₂
合在一起：ΔF ≈ JΔx（把 Δx 看成一列）

例如 Δx=[0.1,0]，预测 ΔF≈[0.4,0.3]；重新计算得到实际变化 [0.41,0.3]。

动手：观察一个输入怎样影响两个输出

和梯度的关系：若只有一个输出，雅可比按本课约定是一行的偏导表；梯度则按输入形状排列。在列向量记法下，这一行雅可比是梯度的转置。两者记录的是同一组偏导。

04 / 一个具体函数的求导例子

矩阵求导例子：所有元素平方后求和

本节只推导这一个函数：f(A)=sum(A ⊙ A)。得到的 ∂f/∂A=2A 是这个函数的求导公式，不是所有标量函数对矩阵求导都能使用的公式。“标量函数对矩阵求导”是一类问题的名称，本例只是其中一种。

这个函数对整个矩阵做了什么运算？

定义“每个元素平方，再把所有元素相加”的函数。⊙ 表示相同位置的元素相乘，sum 在这里表示把整张矩阵的所有元素相加：

A=[[a,b],[c,d]]
A ⊙ A = [[a²,b²],[c²,d²]]
f(A)=sum(A ⊙ A)=a²+b²+c²+d²

例如 A=[[1,2],[3,4]]，先得到 [[1,4],[9,16]]，再把四个数相加，得到 30。输入是一张矩阵，输出是一个数。

这里 A ⊙ A 是逐元素乘法，不是矩阵乘法 A @ A。前者每格只乘它自己；后者按行与列相乘再相加，下一部分会单独讲。

展开后，逐个元素求导

现在把同一个函数写成四个标量变量的表达式：

A=[[a,b],[c,d]]
f(A)=a²+b²+c²+d²

它就是普通的四元函数 f(a,b,c,d)。对 a 求导时，b、c、d 不动；其他元素同理。

改变哪个元素固定哪些元素得到的偏导
a=A₁₁b、c、d∂f/∂a=2a
b=A₁₂a、c、d∂f/∂b=2b
c=A₂₁a、b、d∂f/∂c=2c
d=A₂₂a、b、c∂f/∂d=2d
∂f/∂A = [[∂f/∂a,∂f/∂b],
　　　　 [∂f/∂c,∂f/∂d]]
　　　 = [[2a,2b],
　　　　 [2c,2d]]=2A

矩阵梯度的逐元素定义：只让第 i、j 个位置增加 ε，其他位置保持不变。Eᵢⱼ 表示“只有第 i、j 格为 1，其余为 0”的矩阵。

(∂f/∂A)ᵢⱼ = ∂f/∂Aᵢⱼ
　= limε→0 [f(A+εEᵢⱼ)−f(A)] / ε

矩阵梯度的意义：预测各个格子的改动对函数值的影响

A=[[1,2],[3,4]] 时，f=1²+2²+3²+4²=30，梯度为 [[2,4],[6,8]]。它的第一行第二列为 4，表示只让 b 增加 ε，f 大约增加 4ε。

例如只让 b 增加 0.1，预测变化为 0.4；实际 f([[1,2.1],[3,4]])−30=0.41。

多个格子同时改动：
Δf ≈ 2aΔa + 2bΔb + 2cΔc + 2dΔd
　 = Σᵢⱼ (∂f/∂Aᵢⱼ)ΔAᵢⱼ

Σᵢⱼ 表示把所有位置的项相加。这是梯度与改变量对应位置相乘，再全部相加，不是两张矩阵做矩阵乘法。

动手：只改动矩阵的一个格子

固定起点 A=[[1,2],[3,4]]，f(A)=30。

把求导结果写回矩阵形式

f(A)=sum(A ⊙ A)
每格的偏导：∂f/∂Aᵢⱼ=2Aᵢⱼ
所有格子排回原位置：∂f/∂A=2A

这里 2A 就是把 A 的每个元素乘 2。这个结论来自本例中“每格贡献自己的平方”。换一个函数，偏导表达式就可能不同，必须按新的函数重新求导。可以复用的是“逐个求偏导，再按原位置排列”的方法，而不是 2A 这个结果。

05 / 具体例子：矩阵乘自己

先算清楚输出，再对每个输出求偏导

上一部分的函数输出一个数。这一部分换一个函数：输入矩阵 A，计算 A 和自己做矩阵乘法，输出仍然是一张矩阵。

① 先解释记号和乘法

F(A) 表示“把矩阵 A 交给函数 F 后得到的结果”。这里定义 F(A)=A @ A，@ 表示矩阵乘法；这也常写作 A²。它与上一部分的逐元素平方不同。

矩阵乘法的一个输出元素怎么计算？取左边矩阵的一行、右边矩阵的一列，对应位置相乘，再把乘积相加。先看左上角：

A=[[a,b],[c,d]]
左边第一行：[a,b]
右边第一列：[a,c]
左上角的输出：a×a+b×c=a²+bc

其他三个位置也用同样的方法。F₁₁ 表示输出矩阵第一行第一列的数，F₁₂ 表示第一行第二列的数；下标只是在标明位置。

输出位置取哪一行和哪一列展开计算
F₁₁第一行与第一列a×a+b×c=a²+bc
F₁₂第一行与第二列a×b+b×d=ab+bd
F₂₁第二行与第一列c×a+d×c=ac+dc
F₂₂第二行与第二列c×b+d×d=bc+d²
F(A)=[[a²+bc,ab+bd],
　　　[ac+dc,bc+d²]]

② 每个输出，分别对四个输入求偏导

先只看左上角的输出 F₁₁=a²+bc：

  • 对 a 求导：b、c、d 固定，得到 2a。
  • 对 b 求导：a、c、d 固定，得到 c。
  • 对 c 求导：a、b、d 固定，得到 b。
  • 对 d 求导：表达式里没有 d，得到 0。

这就算出了一个输出对应的四个偏导。对另外三个输出也分别这样计算，一共得到 16 个偏导。仍然使用前面学过的雅可比排列方法：每一行对应一个输出，每一列对应一个输入。

输出函数对 a 求导对 b 求导对 c 求导对 d 求导
F₁₁=a²+bc2acb0
F₁₂=ab+bdba+d0b
F₂₁=ac+dcc0a+dc
F₂₂=bc+d²0cb2d

输入按 [a,b,c,d] 排列；输出按 [F₁₁,F₁₂,F₂₁,F₂₂] 排列。表中的四行四列就是这个顺序下的雅可比。不要把它当成新的求导公式，每个格子都是刚才那种普通偏导。

③ 这些偏导有什么用？只改一个输入试试

设 A=[[1,2],[3,4]]，即 a=1、b=2、c=3、d=4。只让 b 增加 0.1，其他元素保持不变。取上表“对 b 求导”的一列：

四个输出对 b 的偏导：[c,a+d,0,c]=[3,5,0,3]
每个偏导乘改变量 0.1：
F₁₁ 的变化约为 3×0.1=0.3
F₁₂ 的变化约为 5×0.1=0.5
F₂₁ 的变化约为 0×0.1=0
F₂₂ 的变化约为 3×0.1=0.3

把这四个输出的变化放回各自的位置，就得到预计的输出变化：

[[0.3,0.5],[0,0.3]]

④ 用实际计算核对

原输入 A=[[1,2],[3,4]]
原输出 A @ A=[[7,10],[15,22]]

改后输入：[[1,2.1],[3,4]]
改后输出：[[7.3,10.5],[15,22.3]]

改后输出减去原输出：
[[7.3−7,10.5−10],[15−15,22.3−22]]
= [[0.3,0.5],[0,0.3]]

这次结果与偏导估计恰好相等，因为只改变 b 时，四个输出关于 b 都是一次式。对于其他改动，估计与实际结果未必完全相等；前面平方函数的例子已经展示过这种差别。

本例学到的方法：先展开矩阵乘法，找出每个输出函数；再固定其他输入，逐个求偏导；最后用“偏导×小改变量”解释输出怎样变化。这里不需要额外的抽象导数记法。

06 / 复合函数

中间变量也是函数，逐条应用链式法则

定义两个中间变量，再把它们代入一个标量函数：

u=x₁+x₂，v=x₁−x₂
f=u²+3v²

x₁ 会同时改变 u 和 v，因此两条影响都要计算并相加：

∂f/∂x₁ = (∂f/∂u)(∂u/∂x₁) + (∂f/∂v)(∂v/∂x₁)
　　　 = 2u×1 + 6v×1 = 2u+6v
∂f/∂x₂ = 2u×1 + 6v×(−1) = 2u−6v

在 x=[2,1] 时，u=3、v=1，∇f=[12,0]。这只是普通复合函数的偏导计算。也可以先展开 f=(x₁+x₂)²+3(x₁−x₂)²，直接求偏导，核对结果。

向量函数的链式法则

若 u=G(x)、y=H(u)，每个输出对每个输入都有多条中间路径：

∂yᵢ/∂xⱼ = Σₖ (∂yᵢ/∂uₖ)(∂uₖ/∂xⱼ)
按雅可比排列：Jy,x = Jy,u Ju,x

矩阵乘法在这里刚好把“各条路径贡献相乘再相加”组织在一起。

07 / 检查自己算得对不对

用小改动核对偏导

按定义，只改一个输入元素，计算函数值的变化。用加 ε 和减 ε 的中心差分，近似偏导：

∂f/∂Aᵢⱼ ≈ [f(A+εEᵢⱼ)−f(A−εEᵢⱼ)]/(2ε)

对向量也一样，每次只改一个分量；输出有多个分量时，对每个输出分别计算差分。数值结果用于检查手推公式，不是新的求导规则。ε 过大会有近似误差，过小又可能受到浮点舍入影响。

配套计算例子只核对本页的数学函数，包括梯度、雅可比、矩阵输出的导数和链式法则。可选运行：

uv run python lessons/lesson-math-matrix-calculus.py

先手算的三道练习

  1. f(x)=x₁x₂+x₂²：求梯度，并代入 x=[2,3]。
  2. F(x)=[x₁+x₂²,x₁x₂]：逐行计算雅可比。
  3. A=[[a,b],[c,d]]、f(A)=ab+c²−d：求矩阵梯度，解释 b 改动时 f 的变化率。
展开核对答案
1. ∇f=[x₂,x₁+2x₂]，代入后为 [3,8]
2. J=[[1,2x₂],[x₂,x₁]]
3. ∂f/∂A=[[b,a],[2c,−1]]；b 的偏导为 a
